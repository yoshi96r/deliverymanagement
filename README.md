# Base44 App


This app was created automatically by Base44.
It's a Vite+React app that communicates with the Base44 API.

## Environment setup

1. Copy `.env.example` to `.env.local` in the project root (next to `package.json`).
2. Fill in the values from your Base44 dashboard:
   - `VITE_BASE44_APP_ID` – your app's ID
   - `VITE_BASE44_API_URL` – usually `https://api.base44.app`
3. Restart the dev server after updating env values.

## Running the app

```bash
npm install
npm run dev
```

## Building the app

```bash
npm run build
```
